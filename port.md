SaaS de monitoramento cognitivo para crianças com TDAH. A plataforma recebe métricas do jogo e fornece análises médicas detalhadas.

**Engenharia & Arquitetura:**
- **Motor Analítico:** API em Python (FastAPI) e MongoDB processando métricas complexas de tempo de reação em tempo real.
- **Segurança & Integração:** Pareamento entre Web e Mobile (Unity) via PIN efêmero e JWT, com dados blindados por Hashing Bcrypt.
- **Infraestrutura:** Proxy reverso com Nginx, relatórios via DOM Fantasma e deploy orquestrado via Docker (VPS) e Vercel.
